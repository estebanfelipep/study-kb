# aws — index

This folder covers Amazon Web Services. Facts about individual services live in `aws-services/`. Each study track or certification gets its own subfolder, which links to the service files rather than repeating them.

Read `data-engineering/` instead for data engineering concepts that hold regardless of vendor.

## Files

- [aws-services/](aws-services/aws-services.md): one file, or folder, per AWS service. Read when: you need how a specific service works, its limits, pricing model, or integrations.
- [aws-data-engineering/](aws-data-engineering/aws-data-engineering.md): the AWS data engineering track and the AWS Certified Data Engineer – Associate (DEA-C01) exam. Read when: you need exam facts, domains, study progress, how services combine into data pipelines, or exam traps.
