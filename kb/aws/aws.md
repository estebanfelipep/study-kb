# aws — index

This folder covers Amazon Web Services. Facts about individual services live in [aws-services/](aws-services/aws-services.md). Each study track or certification gets its own subfolder, which links to the service files rather than repeating them.

Read [data-engineering](../data-engineering/data-engineering.md) or [ai](../ai/ai.md) instead for concepts that hold regardless of vendor.

## How to read this folder

- **Before:** [data-engineering](../data-engineering/data-engineering.md) for the data engineering track, and [ai](../ai/ai.md) for the AI engineering track. Each track assumes its subject's concepts.
- **Order:** follow a track, and open service files only when the track points to one. `aws-services/` is a reference, not something to read through.

## Files (in reading order)

- [aws-data-engineering/](aws-data-engineering/aws-data-engineering.md): the AWS data engineering track and the AWS Certified Data Engineer – Associate (DEA-C01) exam. Read when: you need which services fit each pipeline stage, how to choose between services, or exam traps.
- [aws-ai-engineering/](aws-ai-engineering/aws-ai-engineering.md): the AWS AI engineering track: how AWS services combine to build generative AI systems, such as model chains. Read when: you need which AWS services coordinate a multi-step AI workflow.
- [aws-services/](aws-services/aws-services.md): one file, or folder, per AWS service. Read when: you need how a specific service works, its characteristics, limits or a usage example.
