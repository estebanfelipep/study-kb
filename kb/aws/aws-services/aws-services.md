# aws-services — index

This folder holds one file per AWS service, named after the service in kebab-case (`s3.md`, `glue.md`, `kinesis-data-streams.md`). A service's facts live here, whichever certification or track they came up in. Once a service has several files, it moves into its own subfolder with an index (`glue/glue.md`).
