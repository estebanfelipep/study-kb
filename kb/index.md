# Study KB — index

Start here. This file lists only the KB's first layer: the subject folders and the reference files. Each subject's index is the reading guide to what's inside it.

## How to read this KB

- **Order:** start with [data-engineering](data-engineering/data-engineering.md) for the concepts, then [aws](aws/aws.md) for how AWS implements them and for the DEA-C01 track.
- **To answer a question,** open the subject's index and follow the indexes down. Don't read the whole KB.

## Subjects

- [data-engineering](data-engineering/data-engineering.md): vendor-neutral data engineering concepts: the role, discovery, the pipeline stages, storage, streaming, orchestration, and security and monitoring. Read when: you need a concept that holds regardless of vendor.
- [aws](aws/aws.md): Amazon Web Services: one file per service, and the AWS certification tracks being studied (DEA-C01). Read when: you need how an AWS service works, which one to pick, or exam prep.

## Reference

- [context.md](context.md): the glossary of terms and abbreviations. Read when: a term, acronym, or service nickname is unfamiliar, or two names might mean the same thing.
- [links.md](links.md): every external link in the KB, grouped by kind (official docs, courses, practice exams, videos). Read when: you need a URL, or want to know where a resource lives.
- [AGENTS.md](../AGENTS.md): how this KB is organized and run.
